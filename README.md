# Отслеживание богослужений на церковнославянском языке
Проект представляет собой веб-приложение, которое поможет пользователям следить за текстом богослужения. 
Приложение позволяет записывать аудио во время богослужения, находить текст отрывка богослужения, который был записан и переходить к полному тексту богослужения, конкретно к тому отрывку, который был найден.

## Как это работает

1. Пользователь нажимает кнопку записи и записывает фрагмент богослужения.
2. Аудио отправляется на сервер, конвертируется в WAV (16 kHz, моно).
3. Модель Whisper распознаёт речь в текст.
4. Текст нормализуется и ищется в текстах сегодняшних богослужений.
5. Пользователю показываются 3 лучших совпадения с оценкой уверенности.
6. При переходе открывается полный текст богослужения и прокручивается
   к найденному фрагменту.

## Технологии

**Backend**
- FastAPI
- Whisper (дообученная модель)
- BeautifulSoup4 — парсинг текстов богослужений с azbyka.ru
- RapidFuzz — нечёткий поиск фрагмента
- ffmpeg — конвертация аудио

**Frontend**
- React
- React Router
- Vite


## Модель и датасет

### Датасет на церковнославянском языке
https://huggingface.co/datasets/bimbo-girl/church-slavonic-language

- Суммарная длительность: 1 час 59 минут 27 секунд
- train — 1540 файлов
- validation — 117 файлов
- test — 124 файла

Метаданные:
- `service_type` — тип богослужения
- `service_date` — дата богослужения
- `church_name` — название церкви
- `city` — город церкви

### Дообученная модель Whisper
https://huggingface.co/bimbo-girl/whisper-small-church-slavonic

Модель `whisper-small`, дообученная на датасете выше.
